# Project report (B.Tech format)

- `PROJECT_REPORT.docx` / `PROJECT_REPORT.pdf`: the report. Fill in the bracketed fields on the title, certificate, declaration and acknowledgement pages in the .docx.
- `src/`: report text (custom markup, see the header of `scripts/build_project_report.py`). `src/90_appendix.md` is generated by `scripts/report_appendix.py`.
- `figures/`: figures (from `scripts/report_figures.py`, KiCad exports and renders).
- `evidence/`: outputs of the checks and models re-run for the report on 20 Nov 2026.

Rebuild: `python scripts/report_figures.py && python scripts/report_appendix.py && python scripts/build_project_report.py` (needs LibreOffice, poppler-utils, python-docx, matplotlib).
